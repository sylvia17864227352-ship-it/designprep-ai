# DesignPrep AI

DesignPrep AI is an AI-assisted design history learning and question-answering system.

## Project Goal

The project aims to help industrial design students retrieve, understand, and review design history knowledge through a lightweight question-answering workflow.

## Initial Scope

- Local knowledge cards
- Question input
- Knowledge retrieval
- Answer generation
- Source display
- Basic evaluation

## Project Structure

- `src/` core application code
- `data/` knowledge cards and test data
- `tests/` test files
- `docs/` product and development documentation
