# Product Scope

## 1. Target Users

Industrial design students preparing for postgraduate entrance examinations who need to review design history knowledge efficiently.

## 2. Core Problem

Design history contains many fragmented concepts, designers, movements, works, and chronological relationships. Students often spend significant time locating relevant information across notes and textbooks.

## 3. Product Goal

Build a lightweight question-answering system that helps users:

- Ask natural-language questions about design history
- Retrieve relevant knowledge cards
- Obtain concise answers based on retrieved content
- View the source knowledge used for the answer
- Evaluate whether retrieval and answers are useful

## 4. MVP Scope

The first version will include:

1. Local structured knowledge cards
2. Question input
3. Basic retrieval
4. Answer generation
5. Source display
6. Simple evaluation dataset

## 5. Out of Scope

The MVP will not include:

- User accounts
- Payment
- Large-scale cloud deployment
- User-uploaded textbooks
- Complex recommendation systems
- Fine-tuning large language models

## 6. MVP Success Criteria

The MVP is considered usable when:

- A user can enter a question
- The system retrieves at least one relevant knowledge card
- The system returns an answer
- The answer includes source information
- A small evaluation set can be used to verify retrieval quality
